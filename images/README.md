# Project screenshots

Add your UI and demo images here so they appear on GitHub when you commit and push.

## What to add

Suggested names (optional):

| File | Suggestion |
|------|------------|
| `login.png` | Login page |
| `dashboard.png` | Main detection screen after login |
| `prediction-result.png` | Example analysis with confidence |
| `disease-compare.png` | Disease comparison modal |

## Upload steps

1. Save screenshots as `.png`, `.jpg`, or `.jpeg` in this folder.
2. From the project root, run:
   ```bash
   git add images/
   git commit -m "Add project screenshots"
   git push
   ```

## Use in the main README

In the repo root `README.md`, you can embed an image with:

```markdown
![Dashboard](images/dashboard.png)
```

GitHub will show the image on the repository page.
